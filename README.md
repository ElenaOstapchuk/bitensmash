# Bite & Smash

Stealth mosquito game - Unreal Engine 5.8 (C++ + Blueprints). Targets: PC (Steam), Android, iOS.

- `BiteAndSmash.uproject` - open with UE 5.8 (needs Visual Studio 2026 + Windows SDK 10.0.26100)
- `Source/` - C++ game module
- `Content/BiteAndSmash/` - game assets
- `SourceArt/` - Blender source files (.blend) and FBX exports
- The original Unity prototype lives on the `unity-prototype` branch.

Large binary files (.uasset, .umap, .blend, .fbx) are stored with Git LFS.
